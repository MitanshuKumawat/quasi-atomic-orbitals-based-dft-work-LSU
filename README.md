# Quasi-Atomic Orbitals-Based DFT

Selected computational work on quasi-atomic orbital (QAO) methods and numerical techniques for electronic structure calculations.

## Overview

This repository documents selected aspects of my research work at **Louisiana State University (LSU)** under the supervision of **Dr. Craig Plaisance**.

The project involved exploring computational approaches based on quasi-atomic orbitals (QOs) within density functional theory (DFT), with an emphasis on numerical methods and efficient electronic structure representations.

The work involved developing, implementing, and investigating MATLAB-based routines for various computational components of the framework.

## Areas of Work

The repository contains selected implementations related to:

- **Hamiltonian Construction:** Numerical routines involving Hamiltonian representations and associated operations.
- **Numerical Methods:** Fourier-based transformations, filtering operations, and multiresolution numerical techniques.
- **SCF Algorithms:** Self-consistent field calculations, iterative convergence methods, and associated numerical procedures.

## Repository Structure

| Directory | Description |
|---|---|
| `hamiltonian/` | Hamiltonian-related computational routines |
| `numerical_methods/` | FFT, filtering, and numerical transformation routines |
| `scf/` | SCF-related algorithms and computational routines |

## Implementation

The computational work was primarily carried out in MATLAB.

The repository contains selected components from a broader research effort. It is intended to provide an overview of the computational methods and numerical techniques explored during the project, rather than serve as a complete or independently executable implementation.

## Repository Status

**Work in progress.**

The research and development of the broader computational framework are ongoing. Consequently, this repository intentionally includes only a subset of the associated implementation.

Some dependencies, research-specific routines, and implementation details are not included.
